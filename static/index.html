How It Works
Multi-Agent Intelligence Pipeline

Five specialist IBM Granite-powered agents work in parallel, each focused on a different aspect of disaster management, then fuse into a single executive briefing.

01
🛰️
Data Ingestion
Field operators input storm position, pressure, SST, wind speed and coastal data.
02
⚡
Agent Dispatch
The orchestrator launches all specialist agents simultaneously using parallel threads.
03
🧠
IBM Granite AI
Each agent queries IBM Granite-4-h-small on watsonx.ai with domain-specific prompts.
04
🔗
Output Fusion
All agent outputs are fused into a single Executive Briefing by a dedicated Granite call.
05
📋
Unified Decision
District administrators receive one unified brief with actions, risks and resource gaps.
