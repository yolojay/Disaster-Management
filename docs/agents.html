Five specialist agents, each purpose-built for a critical phase of cyclone disaster management — all powered by IBM Granite-4-h-small via watsonx.ai. Click any agent to launch its interface.

Cyclone Track & Intensity Prediction
Pre-Landfall

Analyses sea-surface temperature, atmospheric pressure, wind shear and position data to forecast the 72-hour cyclone track, intensity category, storm-surge height and landfall timing.

Capabilities
72-hour track forecast (lat/lon waypoints)
Intensity categorisation (Saffir–Simpson 1–5)
Landfall timing & location estimate
Storm-surge height prediction
Key uncertainty factor analysis
